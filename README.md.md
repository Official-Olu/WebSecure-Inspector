**WebSecure Inspector**

A browser extension that checks the pages you visit for common client-side security mistakes and gives each site a security score from 0 to 100.

Built for amateur and beginner student developers who want quick, plain feedback on the security of their own websites. Works in Chrome and Firefox.

**To Install this Extensions on Firefox or Chrome**

**First, get the code:**

On this page, click the green Code button, then Download ZIP.
Unzip the file somewhere you can find it.

Then follow the steps for your browser.

**For Chrome**
Open chrome://extensions/ in a new tab.
Turn on Developer mode (top right).
Click Load unpacked.
Select the chrome/ folder from the unzipped files.


**For Firefox**
Open about:debugging#/runtime/this-firefox in a new tab.
Click Load Temporary Add-on.
Select the file firefox/manifest.json from the unzipped files.

**Firefox note**: temporary add-ons are removed when Firefox closes, so you will need to load it again after restarting the browser.
