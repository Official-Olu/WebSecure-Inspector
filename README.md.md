WebSecure Inspector



Real-time detection of client-side web security misconfigurations.



**Features of the browsers extension**

\- Mixed Content detection

\- Unsafe Links detection

\- Insecure Storage detection

\- Security scoring (0-100)



**For Installation of any browsers** 



**For Chrome Installation**



1\. Go to chrome://extensions/

2\. Enable "Developer Mode"

3\. Click "Load unpacked"

4\. Select the chrome/ folder



**For Firefox Installation**



1\. Go to about:debugging#/runtime/this-firefox

2\. Click "Load Temporary Add-on"

3\. Select firefox/manifest.json



**How It Works**

Analyzes HTTPS websites for client-side security vulnerabilities and assigns a security score.



**Browsers Supported**

\- Chrome 90+

\- Firefox 90+
